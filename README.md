# Story Studio — etapa A / experimentální pilot

75sekundový animovaný 2.5D vizuální prototyp. Obsahuje pohyb končetin, chůzi/běh, vrstvené prostředí, mlhu, titulky a scénické přechody. **Zatím bez dabingu, hudby, zvukových efektů, storyboardového schvalování a automatického generování postav.** Není to hotový pilot ani ověřená produkční aplikace.

## Cloudový postup
1. Založ veřejný GitHub repozitář `story-studio`.
2. Nahraj obsah tohoto ZIPu do kořene repozitáře, včetně `.github/workflows/render.yml`.
3. Otevři záložku Actions a povol workflows, pokud to GitHub vyžádá.
4. Otevři `Render pilot` → `Run workflow`.
5. Po doběhnutí stáhni ZIP z části Artifacts. Obsahuje MP4.

U veřejného repozitáře nepovažuj artifacts ani logy za soukromé. Výstup se automaticky odstraní po jednom dni. Nepřidávej API klíče do kódu.
