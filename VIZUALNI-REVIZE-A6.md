# MIMO SIGNÁL — A6 / Grafická revize

## Co se mění oproti A5

- 24 záběrů, střih a šest vypravěčských částí zůstávají.
- Nový vlastnoručně kreslený 2.5D les s více hloubkovými plány, horskou siluetou, různými typy stromů, kameny, vegetací a stezkou.
- Světlo měsíce, jemné prachové částice, mlha, dynamické parallax posuny a filmové okrajové ztmavení.
- Kompletně překreslený Adam: vrstvená bunda, batoh, kapsy, obličej, oči a mimika, texturované vlasy, boty a telefon.
- Samostatně animované paže a nohy + chůze/běh, bobbing těla a otočení hlavy; postava není statický obrázek.
- Odlišné velikosti hrdiny pro detaily a celky; výraznější kompozice coveru.
- Kontrastnější paleta pro vlastní identitu MIMO SIGNÁL, bez kopírování dodaných videí.

## Otevřené limity

- Jde o propracovanější **originální vektorovou herní ilustraci**, stále však ne o ručně vytvořenou 3D scénu nebo filmovou postavu z komplexního animačního softwaru.
- Dlouhodobě nejlepší výsledek přinese sada konzistentních barevných/rigovaných postav ve více úhlech s novou vrstvou scénických animací.
- Nyní nejsou na generování obrázků použity placené API služby. Není nutná instalace na uživatelském notebooku.
- Před publikováním je nutné zkontrolovat výsledný cloudový MP4; syntaxe zdrojového kódu není totéž jako finální render.

## Nasazení

1. Rozbal balíček a zkopíruj jeho obsah do lokálního repozitáře v GitHub Desktop.
2. Commit to main, Push origin.
3. Actions → MIMO SIGNÁL | Render pilot → Run workflow → `manual`.
4. Stáhni artifact `mimo-signal-part01-manual`, otevři MP4 a `cover.jpg`.
5. Ověř grafiku na skutečném telefonu a zašli výsledek k dalším úpravám.
